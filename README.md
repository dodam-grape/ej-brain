# 은정 Brain v10 오늘의 일정관리 다이어리 (2026-08-11)

기존 Firebase/Google 로그인과 PC·모바일 동기화를 그대로 유지하면서 기능을 확장한 GitHub Pages용 버전입니다.

## 교체 방법

1. 압축파일을 풉니다.
2. GitHub의 `ej-brain` 저장소에서 `index.html`, `app.js`, `style.css`, `manifest.json`, `firebase-config.js`, `firestore.rules`, `README.md`를 새 파일로 교체합니다.
3. `Commit changes`를 누릅니다.
4. GitHub Pages 반영에는 보통 몇 분이 걸립니다. 화면이 그대로라면 강력 새로고침하거나 모바일 브라우저를 완전히 종료한 뒤 다시 접속합니다.

## 이번 버전의 핵심

- 앱 시작화면을 날짜별 일정관리 다이어리로 변경
- 오전 6시~밤 11시 시간별 계획·완료체크·오늘의 핵심목표
- 날짜별 미팅·체크리스트·자유메모와 자동 저장
- 기존 홈은 ‘수집함’으로 보존하고 모바일 전체메뉴에서 접근
- 자산대시보드: 고정비·변동비를 카테고리별 원형그래프와 금액·비율·순위로 분석
- ‘월예산 가이드’를 가장 많이 쓴 항목과 전월 증감을 보여주는 ‘이번 달 소비 진단’으로 교체
- 월별가계부에서 카테고리별 월예산 영역 삭제(기존 저장자료는 보존)
- 가계부 총지출과 고정비에 할부현황의 월 할부금을 자동 합산
- 고정비 사용내역을 다음 달부터 같은 날짜와 설정으로 자동 반복 표시
- 자산대시보드: 고정비·변동비 항목별 소비분석
- 할부현황: 월 할부금을 해당 카드값에 포함하고 카드 실적 및 대출 잔액에서는 제외
- 도담·소담 달력: 도담·소담·중요·보통 네 가지 분류와 서로 다른 색상

- 모든 기록에 추가·수정·삭제·저장
- 업무달력: BR(분홍), DD(주황), 중요(노랑), 보통(파랑), 일정 상세창 수정·삭제, 주말·공휴일 색상
- 홈: 할 일과 업무 일정을 분리하고 업무 일정은 ‘다가오는 일정’에만 표시
- 기존 업무달력 자료가 할 일 형식으로 저장된 경우에도 업무달력과 ‘다가오는 일정’에 복원 표시
- 연간계획: 1~12월 × 업무·가족·도담·소담·자산
- 도담·소담: 아이 일정 달력·매일 루틴시간표·연간로드맵·성장로드맵
- 여행: 계획과 기록
- 카드실적: 신한·하나·롯데·삼성, 실적 포함/미포함, 목표까지 남은 금액
- 월별 가계부: 고정비·변동비 구분, 월말결산과 전월 비교
- 자산관리: 현금·예금, 대출, 보험, 주식, 기타(대시보드 제외), 할부, 부동산
- 부동산·이사: 수리·구매·처분 구분, 진행률·비용·기한·메모
- 자기계발·목표관리 메뉴 제거(기존 저장 데이터는 보존)
- 모바일 하단 탭: 홈·업무·도담소담·자산·연간
- 모바일 상단 전체메뉴(☰): 여행·부동산·이사 바로가기

## 기존 데이터

기존 Firebase 데이터는 새 구조에 맞게 자동 보완됩니다. 기존 할 일·일정·가계부·자산자료를 지우지 않고 새 항목을 추가합니다.

## 보안

`firestore.rules`는 기존에 Firebase 콘솔에 게시한 규칙과 동일합니다. 이미 게시했다면 Firebase 콘솔에서 다시 설정할 필요가 없습니다.
