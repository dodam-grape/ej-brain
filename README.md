# 은정 Brain v15 — 가로형 예산 계산표

## v15 화면 개선
- 예산은 이사·임시거주, 23평 공사, 31평 공사, 계약·정산, 기타로 묶어 소계 표시.
- 항목명 옆 입력칸에서 만 원 단위로 직접 수정. 전체 화면 재렌더 없이 소계·예비비·총액·잔액 갱신.
- 상세 수정창도 만 원 단위. 저장 데이터는 원 단위를 유지.
- PC 예산 2열 및 체크리스트 최대 3열, 모바일 체크리스트 2열.
- 기존 moveProjectVersion 유지: 이번 업데이트는 기록을 초기화하거나 삭제하지 않음.
- 로컬 문법/로직 테스트 통과. 브라우저 시각 검증은 실행환경 권한 제한으로 미완료.

## v14 이사 프로젝트 교체
- 사용자 요청으로 이전 moveItems 전체를 새 일정 7개·예산 13개·체크리스트 10개로 교체합니다.
- moveProjectVersion 마커로 1회만 교체합니다. 이후 수정·삭제·완료 체크는 재접속해도 유지됩니다.
- Google 로그인 시 Firestore 트랜잭션으로 state.moveItems 및 state.moveProjectVersion만 교체합니다.
- 부동산·가계부·대출 등 다른 기록은 교체 대상이 아닙니다.
- 이전 이사 기록을 별도 백업하지 않습니다. 앱 안에서 삭제 취소는 제공하지 않습니다.
- 기본 22,400,000원 + 예비비 10% 2,240,000원 = 총 24,640,000원.
- 예산 입력은 원, 화면 표시는 만 원. 예산을 수정하면 예비비와 총액은 자동 재계산합니다.
- 대출 접수 목표 35,000,000원은 일정 참고 정보이며 예산/대출에 자동 등록하지 않습니다.
- 보증금 반환·기존 대출 상환은 별도. 2/20 공사 전 23평 인도 가능 여부 확인 필요.
- 실제 Firebase 사용자 데이터 변경은 새 버전 접속·로그인 시 실행됩니다.

GitHub Pages용 개인 기록장. Firebase 설정과 기존 저장자료를 유지합니다.

## 이번 변경
- 오늘 · 메모 · 자산 · 연간 · 이사 순서의 모바일 하단 탭
- 여행은 전체메뉴 및 오늘 화면 별도 버튼으로 접근
- 업무/도담소담 메뉴 제거. 저장자료는 삭제하지 않음
- 시간별 일정만 표시. 기존 미팅/체크리스트/메모 자료는 보존하되 숨김
- 일정 입력 즉시 로컬 보관, 입력 완료/하단 저장 버튼으로 동기화 요청. 입력에 따른 전체 화면 재렌더 제거
- 메모의 그림 이모지를 글자 표식으로 대체. 모바일은 세로로 카테고리 표시
- 변동비·고정비·수입·분석·카드·자산현황 버튼형 관리
- 기존 고정비 매월 반복, 월별 변경 이력, 반복 중단. 할부는 자동 합산
- 이사 체크리스트: 예정일, 우선순위, 예상/실제 비용, 완료 체크
- v14에서 새 이사 대화의 일정·금액·체크리스트로 교체
- 크림·세이지·피치 파스텔 디자인과 터치 버튼 개선
